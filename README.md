# My Task Tracker

A simple and user-friendly task management web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete individual tasks.
- Save tasks using browser Local Storage.
- Retain tasks even after refreshing the page.
- Clean and responsive user interface.

## Technologies Used

- HTML5 – Structure
- CSS3 – Styling
- JavaScript – Functionality
- Git & GitHub – Version Control

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/chawlahritika-lab/git-task-tracker.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
